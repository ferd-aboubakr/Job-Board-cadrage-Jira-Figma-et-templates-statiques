## inital project execution plan ##
###### ###### ###### ###### ####### ####### ###### ###### ###### ###### ####### #######

1. Project Scoping & Jira Setup
Begin by translating the Cahier des charges into an actionable Agile backlog to organize your sprint.

Create your three core Epics in Jira: "Intégration Statique (HTML/CSS)", "Dynamisation JavaScript", and "Fullstack Express/EJS/MySQL".

Draft at least 10 User Stories (e.g., "As an applicant, I want to filter offers by city so that I find local opportunities") and assign them priorities.

Define a clear Definition of Done (DoD) for your tasks, ensuring requirements like mobile responsiveness and accessible contrast ratios are checked off.

2. Figma Design & Architecture
Before writing code, visualize the application's structure and user journey.

Map out a functional sitemap connecting the four core public screens and the simplified back-office interface.

Draft low-fidelity wireframes to establish the visual hierarchy and placement of future interactive elements like filters.

Design high-fidelity desktop and mobile mockups, creating reusable Figma components for the job cards, technology badges, and navigation elements.

3. Front-End Integration
Translate your designs into a clean, static codebase without relying on JavaScript frameworks or backend logic.

Initialize your repository using the requested folder structure with your index.html, offre-detail.html, deposer-offre.html, and offres-suivies.html files.

Configure Tailwind CSS to rapidly build out the responsive components you are familiar with, utilizing Flexbox and Grid to align the offer layouts.

Structure your markup using strict semantic HTML (<header>, <main>, <article>, <nav>) to ensure accessibility and prepare the DOM structure for next week's JavaScript injection.

4. Git Workflow & Final Deliverables
Maintain a professional version control history to demonstrate your iterative development process.

Create and work within dedicated feature branches (e.g., brief-1/figma-design, brief-1/static-templates) before merging into main.

Commit your code frequently with atomic, explicit messages that describe exactly which UI component or template was added.

Finalize your README.md by embedding the required links to your Jira board, Figma workspace, and project documentation files.
